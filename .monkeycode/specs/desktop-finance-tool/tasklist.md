# 需求实施计划 - 单机版桌面财务工具

- [ ] 1. 项目脚手架与基础架构
  - [ ] 1.1 初始化项目
    - 使用 electron-vite 创建 Electron + Vue 3 + TypeScript 项目骨架
    - 安装依赖：electron、vue、pinia、vue-router、element-plus、echarts、better-sqlite3
    - 配置 electron-builder 打包与 better-sqlite3 原生模块构建（`--build-from-source --sqlcipher`）
    - 配置 tsconfig 三份（主进程/预加载/渲染进程）
  - [ ] 1.2 搭建三进程目录结构与安全基线
    - 创建 src/main、src/preload、src/renderer、src/shared 目录
    - 主进程开启 contextIsolation、sandbox，禁用 nodeIntegration，拦截外部导航
    - 预加载层通过 contextBridge 暴露 `window.api`
  - [ ] 1.3 定义 IPC 通道契约与共享类型
    - 在 src/shared 定义数据模型类型与 IPC 通道常量
    - 定义 ledger/transaction/account/category/tag/asset/analytics/backup/export 通道方法签名
  - [ ] 1.4 集成基础 UI 框架
    - 配置 Element Plus（zh-cn locale）、Pinia、vue-router、ECharts
    - 设置全局样式与窗口最小尺寸 1024x700

- [ ] 2. 实现数据模型与 SQLCipher 存储层
  - [ ] 2.1 定义数据模型 TypeScript 接口
    - 编写 Account、Transaction、Category、Tag、TransactionTag、Asset、AssetValue、Liability 接口
    - 编写输入校验函数（金额正数、标签名长度 <= 30 等，对应需求 3.9/9.2）
  - [ ] 2.2 实现 SQLCipher 数据库连接与密码派生
    - 实现 PBKDF2-HMAC-SHA256（600,000 次迭代）密钥派生
    - 实现连接创建：PRAGMA key 注入、cipher_migrate、foreign_keys、WAL
    - 实现密码验证逻辑与错误码映射（INVALID_PASSWORD/CORRUPTED_FILE 等）
  - [ ] 2.3 实现 schema 建表与迁移
    - 编写全部表结构 DDL（含 CHECK 约束与索引，对应设计文档数据模型）
    - 使用 PRAGMA user_version 管理 schema 版本
  - [ ] 2.4 实现仓储层 CRUD
    - 实现 account/category/tag/asset/asset_value/liability 仓储的 CRUD
    - 实现 transaction 仓储的分页查询与动态组合筛选（时间/分类/账户/金额区间/备注/标签）
    - 多表写入封装事务，失败整体回滚
  - [ ] 2.5 实现正确性属性聚合计算
    - 实现账户余额计算（初始余额 + Σ收入 - Σ支出，设计文档属性 2）
    - 实现净资产计算（Σ流动资产 + Σ固定资产 + Σ投资资产 - Σ负债，属性 4）
    - 实现标签删除时解除关联（需求 9.6）
  - [ ]* 2.6 为存储层编写单元与属性测试
    - 属性 1：任意流水金额为正
    - 属性 2/5：账户余额重算与手工计算一致
    - 属性 4：净资产计算正确
    - 各仓储 CRUD、筛选、分页、事务回滚测试

- [ ] 3. 实现账本管理与加密保护
  - [ ] 3.1 实现新建账本流程
    - 引导用户设置密码并选择存储路径
    - 创建加密账本文件、注入密钥、执行建表、写入默认分类种子（需求 1.3/2.1）
  - [ ] 3.2 实现打开账本与密码验证
    - 校验文件存在与权限，派生密钥并验证密码
    - 连续 5 次错误密码锁定会话（需求 1.4/1.8）
  - [ ] 3.3 实现修改加密密码
    - 使用 PRAGMA rekey 实现改密（需求 1.6）
  - [ ] 3.4 实现关闭账本与内存清理
    - 关闭数据库连接，清除内存中密钥引用
  - [ ] 3.5 实现启动自动打开与账本删除
    - 记录最近使用账本路径到 config.json，启动时自动尝试打开（用户可关闭，需求 2.3）
    - 删除账本需二次确认并删除本地文件（需求 2.5）
  - [ ]* 3.6 编写加密安全专项测试
    - 属性 6：错误密码解密失败，文件被篡改后读取失败
    - PBKDF2 迭代次数与密钥长度验证
