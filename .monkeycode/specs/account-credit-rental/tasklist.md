  - [x] 1.1 扩展 Account 类型模型
    - AccountType 增加 'credit'

    - AccountWithBalance/AccountBalanceItem 扩展剩余额度与还款日
  - [x] 1.2 实现 account 表重建迁移（SCHEMA_VERSION 1→2）

  - [x] 2.1 AccountRepository 支持卡号与信用卡字段读写
    - create/update 接受 cardNumber/creditLimit/billDate/dueDate

  - [x] 2.2 accountBalance 聚合返回信用卡剩余额度与还款日
    - 剩余额度 = credit_limit + 余额（余额为负时）

  - [x] 2.3 账户 IPC handler 与 preload 透传新字段
    - account.create/update 参数与返回值携带新字段

  - [x] 2.5 编写存储层单元测试
    - 信用卡余额/剩余额度聚合（多笔消费与还款）、非信用卡忽略额度字段、卡号 CRUD
